# Operator Requirements

## Operator profile

The operator is not expected to know cloud consoles, OAuth, IAM, MCP, or Python internals.

Every required manual step must be written in Turkish and screen-by-screen.

## Frozen operator preferences

- Personal spend target: `$0.00`.
- No paid subscription required for the core build.
- Free trial is acceptable only when auto-renew/paid continuation risk is understood and safely disabled.
- Promotional credits are preferred.
- Never ask the operator to paste secrets into chat.
- Never expose credentials in screenshots/video.
- Development executor: Google Antigravity.
- Independent QA: ChatGPT project workflow against canonical remote.
- Work exactly one Master Plan micro-task at a time.
- User-facing competition materials: English, with Turkish operator guidance where useful.
- Demo may use TTS/captions; English live speaking is not assumed.

## External setup guidance template

Every setup instruction must contain:
1. current official URL;
2. exact console/product name;
3. exact menu path;
4. exact button/link;
5. exact field names;
6. value/selection to use;
7. options NOT to enable;
8. billing/card risk;
9. where secret is shown;
10. how to store it locally;
11. how to verify setup succeeded;
12. what to do when UI differs.

## Irreversible actions

Agent must obtain explicit operator approval before:
- enabling paid billing;
- purchasing/subscribing;
- deleting cloud resources with evidence value;
- publishing a public endpoint that can consume paid quota;
- sending external communication;
- submitting Devpost;
- changing repository visibility after submission freeze;
- merging third-party code with unresolved licensing.
