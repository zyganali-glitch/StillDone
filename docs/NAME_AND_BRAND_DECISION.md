# Name & Brand Decision

Decision date:
`2026-09-20`

## Product name

# StillDone

Display name:
`StillDone`

Repository target:
`zyganali-glitch/StillDone`

Tagline:
> **Done, and still true.**

## Why this name

The product's differentiator is temporal truth.

A normal receipt answers:
> Was it done?

StillDone answers:
> Is it still done?

The name makes the drift/reconciliation feature memorable without using generic AI words.

## Naming principles satisfied

- short;
- easy to pronounce;
- no `AI`, `Agent`, `GPT`, `Flow`, `Pilot`, `Mind`, or `Guard`;
- not a random pseudo-Latin startup token;
- directly connected to the product behavior;
- works as a human phrase;
- supports the canonical demo question.

## Collision research

Planning-time web search did not surface a clearly conflicting exact-name productivity/assistant product.

Planning-time GitHub repository search for `StillDone` returned no repositories.

This is NOT:
- a trademark clearance;
- domain ownership verification;
- legal advice.

Before final public branding/submission, repeat:
- web search;
- GitHub search;
- app store search;
- relevant trademark search if commercial launch is contemplated.

## Brand voice

Calm, factual, low-drama.

Avoid:
- “magical”;
- “autonomous super-agent”;
- “never fails”;
- “guaranteed”;
- anthropomorphic overclaiming.

Preferred vocabulary:
- ready;
- verified;
- needs approval;
- changed;
- no longer ready;
- could not verify;
- not run.

## Primary judge line

> **AI assistants can execute actions. StillDone keeps the outcome true.**

## Closing demo line

> **An assistant shouldn't get credit because it said “done.” Reality gets the final vote.**
