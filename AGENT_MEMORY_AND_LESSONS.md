# Agent Memory & Lessons — StillDone

## Permanent lessons

1. Simulation cannot close a live-required competition task.
2. A tool success response is not proof of resulting state.
3. Read-back must be a separate real observation.
4. Historical proof can become stale; current reality wins.
5. `NOT_RUN` must remain visible.
6. Partial failure is a product state, not an embarrassment to hide.
7. Retry without idempotency can create duplicate real-world effects.
8. Approval must bind to the exact pending action.
9. Broad integrations increase OAuth/privacy risk faster than judge value.
10. Two deep real mutations beat ten decorative integrations.
11. AWS architecture must follow live account/cost reality, not marketing diagrams.
12. Dedicated demo resources are safer and more reproducible than personal production data.
13. Public live endpoints need budget protection.
14. Donor repositories are idea sources, not a shortcut to code reuse.
15. Judge wow should come from a real state transition, not animation.
